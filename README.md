# MathSpan

Personalised tutoring for Classes 9–12 in Physics, Chemistry, Mathematics, Biology and English. One-to-one or small batches of up to five students.

## Run
Open `index.html` in a browser. No build or dependencies required. The supplied MathSpan logo is embedded so the page works as a standalone file.

## Features
- Responsive homepage with animated science diagrams
- Mentor profiles: Aditya Deo Ojha, Anupam Nigam, Karan Kashyap and Anshika Mishra
- Enquiry dialog with input validation and downloadable enquiry copy
- Mathematics quizzes and learning resources

## Enquiries
The form currently downloads a text copy; it does not send or store enquiries on a server. Connect a submission service before enabling direct enquiries.
